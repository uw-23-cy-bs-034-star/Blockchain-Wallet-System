How Diffie-Hellman Works in Blockchain

Step 1: Nodes agree on public parameters (Prime p=29, Base g=3)
Step 2: Each node selects a private key (kept secret)
Step 3: Each computes public key: public = g^private mod p
Step 4: Nodes exchange public keys over the network
Step 5: Each computes shared secret using other's public key
Result: Both get identical shared secret without transmitting it

This ensures secure peer-to-peer communication in blockchain networks.
