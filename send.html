How Digital Signatures Work

1. Transaction data is created (sender, receiver, amount)
2. Transaction is hashed using SHA-256
3. Hash is encrypted with sender's private key → Digital Signature
4. Signature is sent with transaction
5. Network verifies using sender's public key
6. If valid, transaction is added to blockchain
